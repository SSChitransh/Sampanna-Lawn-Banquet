SAMPANNA LAWN & BANQUET WEBSITE

Files
- index.html: complete responsive website, CSS and JavaScript included in one file.

How to preview
- Open index.html in a modern browser. An internet connection is needed for web fonts and the venue photographs.

How to publish with GitHub Pages
1. Create a new public GitHub repository (for example: sampanna-lawn-banquet).
2. Upload index.html to the repository root.
3. Open Settings > Pages, select Deploy from a branch, choose main and /(root), then Save.
4. Wait for the Pages URL to appear.

Before launch
- Confirm the official name, phone/WhatsApp, address, operating details, event types and service inclusions with the venue owner.
- Capacity and pricing are not advertised because public directory entries differ. Add approved figures only after direct confirmation.
- Venue photos currently reference public listing image URLs from WeddingBazaar/WeddingWire. For a production site, get owner-approved, high-resolution photos and permission to use them, then replace the image URLs in index.html with local assets.
- This is a front-end website demo. It does not process online payments or store bookings.
